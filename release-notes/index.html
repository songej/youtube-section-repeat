Release notes

2.0.0 October 3, 2026

  • The welcome page now shows the three keys that make a loop: S, E and R.
  • The player panel keeps actions in consistent positions with their shortcuts. Text is easier to read, speed reset and delete-all labels are clearer, unavailable actions are dimmed instead of disappearing, and Clear all still requires a second press.
  • The first-use guide now shows that pressing E again marks the next section.
  • W is now called focus mode: it leaves the playlist and keeps attention on the video.
  • Backup restore opens in its own tab so the file picker cannot close it.
  • Repeat state is preserved more reliably if Chrome suspends the extension during an update.
  • Unexpected browser startup or maintenance-alarm errors are now contained so one failed event does not destabilize the service worker.
  • Fixed undo after a second delete, saved speed after reload, leftover chapters from another video, description timestamps that do not meet YouTube's chapter rules, typed end times past the video, and several unclear error messages.
