Privacy policy

Last updated: October 4, 2026

In short

Section Repeat for YouTube™ works locally in Chrome. It has no account, analytics, advertising, or developer-operated server. The extension locally processes only the current supported YouTube page/player information and the section data you create so it can save and repeat those sections. The developer receives none of this data and does not sell or share it.

Data the extension handles locally

  • Web browsing data handled locally: the current supported YouTube URL and video identifier are used only to associate your saved sections with that video. Persistent video records use a salted SHA-256 hash rather than the plain video ID.
  • Website content handled locally: the extension reads only the YouTube player/DOM state needed for section timing, playback control, and chapter import. It does not read video pixels, audio, comments, messages, passwords, cookies, or form contents.
  • Your section data: section names, start/end times, playback speed, repeat count, rest time, and related practice settings that you create in the extension.
  • Direct controls: keyboard and pointer input is handled transiently to perform the command you requested. It is not kept as activity history, transmitted, or used for profiling.

What the extension stores

  • Your sections and settings: in chrome.storage.local. Each video's record is keyed by a SHA-256 hash of its video ID and a random salt made for your browser profile, not by the plain video ID.
  • The salt: in chrome.storage.local. For compatibility only, a profile without one can read the salt an older version kept in Chrome Sync so earlier sections stay reachable. The current extension writes nothing new to Chrome Sync.
  • Temporary state: such as the repeat in progress and recovery data, in chrome.storage.session.

In an incognito window, sections last only for that incognito session, and backup and restore are disabled.

Backup and restore

From the toolbar popup you can save your section library to a file and restore it later. The file is created and read on your computer; it is not uploaded. A backup contains the salt and hashed records needed to restore your library, so keep the file private.

Network and tracking

The extension does not send section data, browsing data, player data, or user input to the developer or any third party. It contains no analytics, advertising trackers, telemetry, remote configuration, or network client for user data. Its executable logic is packaged with the extension; it does not load or execute remotely hosted code.

Permissions

  • YouTube and YouTube NoCookie host access: only to run the section-repeat UI and behavior on the supported YouTube player pages.
  • storage: to keep your section library, settings, recovery metadata, and temporary extension state.
  • alarms: to schedule local storage maintenance and retries needed to keep saved section data reliable across Manifest V3 service-worker suspension.

These permissions are not used for advertising, analytics, tracking across sites, or unrelated purposes.

Chrome Web Store Limited Use

Section Repeat for YouTube™ complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide and maintain the extension's single purpose: marking, saving, and repeatedly practising selected sections of YouTube videos. User data is not sold, transferred for unrelated purposes, used for personalized advertising, used to determine creditworthiness, or used to train a general-purpose AI model. Humans do not read extension-handled user data because the extension does not transmit it to the developer or a third party.

Retention and deletion

Saved sections remain in Chrome storage until you delete them, storage maintenance removes older records when space is low, or you uninstall the extension. Temporary session state expires with the Chrome session or is cleared when it is no longer needed. You can delete individual sections in the player panel, delete all sections for a video, or remove the extension to remove its extension storage as Chrome handles uninstall cleanup.

Security

Hashing video IDs keeps them from being readable at a glance in extension storage. It is not anonymity against someone who already has access to your Chrome profile or a backup file. No user data is transmitted by the extension, so there is no developer-side user-data store to secure or retain.

Google services

Your use of YouTube and Chrome is covered by Google's own Privacy Policy and the YouTube Terms of Service.

Changes and contact

This policy is updated when the extension's data handling changes. Questions go through the contact form.
